# 🎓 Course-Reg-Website

A lightweight, responsive web application designed for students to browse and register for electronic engineering courses.

## 🚀 Features
* **Course Catalog:** View detailed lists of available electronics modules.
* **Responsive Design:** Optimized for both desktop and mobile viewing.
* **Fast Navigation:** Simple, intuitive UI for quick registration.

## 🛠️ Tech Stack
* **Frontend:** React.js / HTML5 / CSS3
* **Styling:** Custom CSS

## 📂 Project Structure
* `/public` - Static assets and icons.
* `/src` - React components and core logic.
* `*.html` - Legacy page templates for assessment and learning modules.
